# Workbook Design Guide

## Workbook Goals

A good Sentinel workbook should answer operational questions quickly:

- What changed?
- Who is impacted?
- Which detections are noisy?
- Which incidents are critical?
- Which users or agents are risky?
- Which playbooks failed?

## Recommended Sections

1. Executive summary
2. Incident volume
3. Detection category
4. Entity view
5. Data security view
6. AI security view
7. Automation health
8. Drilldown queries
